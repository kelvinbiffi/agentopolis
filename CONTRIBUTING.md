# Contributing

Issues and pull requests are welcome.

1. `npm install`, then `npm run dev` for the demo.
2. Keep the public API small and event-driven (see `src/types.ts`).
3. Run `npm run typecheck` and `npm test` before opening a PR.
4. Only add 3D art that is CC0 (or another license free for commercial use), and credit it in `CREDITS.md`.
